# Legal Chatbot

Legal Chatbot is an **AI-powered legal assistant** designed to provide users with easy access to general legal information related to Indian law.

The chatbot uses the **Groq API** to generate AI-powered responses and includes **Speech-to-Text (STT)** and **Text-to-Speech (TTS)** for voice-based interaction. A simple **frontend website** is also included for easier access and a better user experience.

## Features

* AI-powered legal assistance using Groq API
* 🇮🇳 Focused on Indian law
* Speech-to-Text (STT)
* Text-to-Speech (TTS)
* User-friendly frontend website
* Conversation-based interaction
* API key protected using environment variables

## Technologies

* Python
* Groq API
* Llama 3.3
* Speech Recognition
* pyttsx3
* HTML
* CSS
* JavaScript

## Disclaimer

Legal Chatbot is for **educational and informational purposes only**. It does not provide professional legal advice. For serious legal matters, consult a qualified lawyer.
